# Zeros of $p$-adic $L$-functions and Refined Random Matrix Conjectures

This directory contains the computational code, algorithms, and numerical verification data accompanying the preprint:

> **Refined random matrix conjectures for zeros of $p$-adic $L$-functions**  
> Heiko Knospe, Jiahe Shen, and Roger Van Peski  
> *Preprint* (2026).

---

## Overview

We study the local distribution, Newton polygons, and field-theoretic splitting behavior of zeros of $p$-adic $L$-functions attached to quadratic Dirichlet characters $\chi$ of discriminant $D$. 

Using Washington’s change of variable:
$$T = (1 + |D|p)^s - 1$$
the Kubota–Leopoldt $p$-adic $L$-function $L_p(s, \chi \omega^i)$ is realized as an Iwasawa power series $f(T) \in \mathbb{Z}_p[[T]]$. By the $p$-adic Weierstrass preparation theorem,
$$f(T) = p^\mu \cdot P_f(T) \cdot U(T)$$
where $P_f(T)$ is a distinguished polynomial of degree $\lambda$ whose roots in the open unit disk $|T|_p < 1$ correspond to the zeros of the $p$-adic $L$-function.

The code in this repository:
1. Approximates $f(T)$ by Lagrange interpolation across negative special values evaluated via PARI's exact algebraic $L$-function routines.
2. Extracts the $\lambda$-invariant and the slopes of the Newton polygon of $P_f(T)$.
3. Factorizes the distinguished polynomial into slope components using $p$-adic Hensel lifting (`factor_of_slope`).
4. Rigorously analyzes the local field extensions $\mathbb{Q}_p(\alpha)$ generated by roots of slope multiplicity $\ge 2$ (unramified, ramified, or split).

---

## Precision and Numerical Guarantees

- **Interpolation:** We interpolate at $N \approx 15 \times p / (p-1)$ nodes in $p\mathbb{Z}_p$.
- **$p$-Adic Working Precision:** Computations are performed in $\mathbb{Q}_p$ with `prec = 50`. The extracted slope factor $g(T)$ retains $\ge 20$ digits of absolute $p$-adic precision.

## Example
Compute Iwasawa power series, lambda, valuation of the constant coefficient,  and zero splitting for $D = 456$, $p = 5$, Teichmuller twist $i = 0$.

```
fp, lam, v0 = power_series(456, 5, 0)
```

```
p=5, twist=0, Fundamental Discriminant=456 ==> lambda=3, v(const)=1, slopes=[1/3, 1/3, 1/3], slope=1/3 v(Disc)=2, ramified field extension of degree 3
```
